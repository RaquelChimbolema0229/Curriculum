# Portafolio educativo de Raquel Anahi Chimbolema Lara

Proyecto de sitio web personal para presentar la identidad académica, vocación docente y perfil profesional de Raquel Anahi Chimbolema Lara, estudiante de Educación Inicial en la Universidad de las Fuerzas Armadas ESPE.

## Descripción

Este portafolio busca compartir una visión amable, creativa y cercana de la educación inicial. A través de una interfaz moderna y visualmente cálida, se presenta información sobre:

- Perfil personal y propósito profesional
- Formación académica
- Experiencias relacionadas con la educación infantil
- Habilidades y herramientas digitales
- Contacto y redes sociales

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Diseño responsivo y accesible

## Cómo ejecutar

Como es un sitio estático, puedes visualizarlo de dos formas:

1. Abrir directamente `index.html` en tu navegador.
2. O ejecutar un servidor local:

```bash
python -m http.server 8000
```

Luego abre en el navegador:

```text
http://localhost:8000
```

## Personalización

Puedes modificar fácilmente:

- textos e información personal en `index.html`
- colores, tipografías y estilo en `styles.css`
- interacciones o animaciones en `script.js`
